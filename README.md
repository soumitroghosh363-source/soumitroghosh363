I'm a **Frontend Developer** and third-year **Mathematics (Honours)** student who builds responsive, data-driven web applications with a strong emphasis on clean architecture and API-readiness. My background in mathematics shapes how I approach state management and UI logic — structured, provable, and edge-case aware.

I design frontends the way backend engineers design APIs: role-gated routes, normalized data layers, and typed contracts that let a real backend swap in for a mock service without touching a single component.

**🎯 Open To:** Frontend engineering roles · Internships · Freelance React/TypeScript projects · Open-source collaboration
